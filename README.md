# DemoBlaze-Manual-Project
##URL-https://www.demoblaze.com/

##INTRODUCTION
Demoblaze(https://www.demoblaze.com/) is an e-commerce website that allows users to signup,login,browse products , add to cart and checkout . This test plan contains objectives scope,tools,deliverables,..... needed to complete the test and it will ensure our product behave as per requirements

##SCOPE
The following features of the website to be tested
User signup
User login
User logout
Product list
Product search
Compare product
Add to cart
Update cart
Checkout
Contact us
